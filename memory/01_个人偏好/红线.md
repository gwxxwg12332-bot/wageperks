# Wage's Perks 红线（最高优先级，每次必看）

## 6条铁律

1. **拆包实锤** — 所有机制结论必须有拆包证据，禁猜测
2. **Debug门控** — 诊断日志用完必删，不靠DebugMode门控留代码
3. **不破坏特性选择界面** — 最高红线，任何操作不能导致Perk选择界面无法交互
4. **挂点规范** — 每帧逻辑走InputActionManager.Update Postfix，禁MelonLoader.OnUpdate
5. **翻译统一** — 蛙哥统一译为Wage（不是Frog），特性名Wage Power
6. **N网文案** — 简介/更新公告/话术直接对话内交付，不写入txt/md文件

## 工作方式偏好

- 写代码前先爬七级阶梯：优先复用游戏原生/已有代码/标准库，不为单个效果新建多个类
- 修bug先grep所有调用者修根因，不补单路径
- mod开发遇到用户反馈失败时，先找拆包AI拆包确认机制根因，不自行猜测原因
- 诊断日志用完必须删除（发布前），不靠DebugMode门控留代码
- 所有可能会导致选不了特性（Perk选择界面无法交互）的办法都不许用
