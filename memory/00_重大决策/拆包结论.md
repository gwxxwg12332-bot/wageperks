## 一、预算系统（StoreClient）

### 1.1 字段布局
| 字段 | 偏移 | 访问 | 说明 |
|---|---|---|---|
| clientCash | 0x30 | public | 客户现金 |
| clientBudget | 0x34 | private | 客户预算（GetBudget 读这个） |
| useClientBudget | 0x38 | public | 是否使用客户预算 |

### 1.2 方法行为
| 方法 | 行为 | 是否调 ApplyBudgetModifier |
|---|---|---|
| SetBudget(int budget) | 写 clientBudget → 设 useClientBudget=1 | ✅ 调 |
| OverrideBudget(int budget) | 只写 clientBudget | ❌ 不调 |
| ModBudget(int budgetMod) | clientBudget += budgetMod | ❌ 不调 |
| GetBudget() | 直接读 clientBudget 字段 | — |
| SetClientBudget(int amount, int additionalRange) | public，创建客户时调 | — |

### 1.3 ApplyBudgetModifier 分支逻辑
1. 检查 useClientBudget（0x38）→ false 直接返回
2. UL_TOP_REVIEW 特权解锁 → 预算 += 当前预算 × 浮点数1
3. SEC_RELIABLE_VENDOR 特权解锁 → 预算 += 当前预算 × 浮点数2
4. 按店铺吸引力分档（GetCurrentStoreAttractiveness）：
   - <300：修正值 = 0
   - 300-450：系数1
   - 450-600：系数2
   - 600-750：系数3
   - 750-900：加当前预算
   - ≥900：加当前预算
- **关键：只加不减，无归零分支**

### 1.4 OnItemSold / OnItemBought
- OnItemSold(GameItem item, int soldAmount)：卖出后预算**增加**（Add [rbx+52]）
- OnItemBought(GameItem item, int cost)：买入后只是触发回调，**不修改预算**
- 成交后预算增加，不是归零

## 三、UI 渲染

### 3.1 显示矩形权威
- **modifiedShape (0x1A0)** 是 UI 显示权威，不是 shape (0x198)
- ValidateSelectLocked L4162：sizeDelta = modifiedShape × 每格 16px
- SetShape 只写 shape，不改 modifiedShape
- SetSpriteAndShape 成功路径才改 modifiedShape（从 sprite 像素 ÷ 16 算 GridShape）
- 失败路径（LoadFromAtlas 返回 null）不改 modifiedShape，无异常

### 3.2 ApplyAnimationFrame
- 只做 Image.set_sprite(frame)，不改 sizeDelta/scale/position
- 帧动画换 sprite 盖不住错误的矩形尺寸
- ppu 与 UI 显示无关（Image 拉伸填充矩形）

## 四、容器系统

### 4.1 PixelWindow 内部读取
- PixelWindow 无 inventory 字段，内部网格挂 childElement
- 正确读取 = childElement.Cast<GameGridInventory>()
- GetAllItems() **不递归容器内部**（只遍历 4 个网格字段顶层 childItems）
- 暗格/箱子内部物品搜不到要额外遍历

### 4.2 smuggler_bay_mod
- identifier 仍是 smuggler_bay，靠 sprite（smuggler_bay_large）区分
- unitValue 400 vs 250，窗口 8×8 vs 5×5
- StartsWith("smuggler_bay") 能匹配升级版

## 六、踩坑结论

### 6.1 实体存在判断
- 实体物品（蛙娘/箱子/容器）天然随 ES3 存档，读档后实体就在
- PlayerPrefs 标记走 default_run 窗口残留（开局 runID 空时写入），新档/跨档必脏
- 正确做法：Exists() = ExistsInScene() 实体查重 → 其次 leaveDay 跑路判定 → 最后才考虑标记

### 6.2 防重入判断
- if (_spIdle != null) return; — 数组引用永远非 null（即使元素全 null），防重入不生效
- 改成元素级：_spIdle != null && _spIdle.Length > 0 && _spIdle[0] != null

### 6.3 PlayerPrefs 删除后必须 Save
- DeleteKey 后不 Save → PlayerPrefs 文件里旧值还在 → 新档读到残留
- 任何删除/重置操作，落盘必须同步
