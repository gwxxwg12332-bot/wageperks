# 发布前检查清单（每次必过）

## 开发版 vs 发布版（严格区分）

### 开发版（电脑上始终保留）
- **路径**：Demo Mods\WagesPerks.dll + 04_产物\WagesPerks.dll
- **保留**：DebugMode开 + 诊断日志 + [蛙诊]/[信誉扫地]/[预算诊断]等刷屏日志
- **用途**：日常开发测试

### 发布版（打包前必须清理）
- **路径**：04_产物\vX.Y.Z\WagesPerks.dll + ZIP
- **必须删**：所有诊断日志（[XXX诊断]/[XXX检查]/[XXX]吃掉等刷屏日志）
- **必须更新**：README.txt 版本号 + ConfigGuide.txt 版本号
- **必须包含**：Mods/WagesPerks.dll + README.txt + 配置教程_ConfigGuide.txt

## 发布前检查清单（每次必过）
1. **版本号**：Core.cs MelonInfo + README.txt 双位置一致
2. **README.txt**：爱发电 https://afdian.com/a/wagesperks + QQ群 1109707341
3. **ConfigGuide.txt**：版本号同步 + CFG项汉化说明
4. **诊断日志**：发布版DLL里无刷屏日志（开发版保留）
5. **MD5三处一致**：Demo + 01发布版 + 04产物
6. **ZIP结构**：Mods/WagesPerks.dll + README.txt + ConfigGuide.txt

## CFG汉化要求
- 所有CreateEntry的描述必须中文
- ConfigGuide.txt 列全CFG项+默认值+说明
- 新增CFG项必须同步更新ConfigGuide
